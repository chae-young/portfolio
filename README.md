# 이채영 포트폴리오

Next.js 14, TypeScript, Tailwind CSS로 구축된 프론트엔드 개발자 포트폴리오입니다.

---

## 🛠 기술 스택

| 항목              | 버전                 |
| ----------------- | -------------------- |
| **Framework**     | Next.js 14.2.20      |
| **Language**      | TypeScript 5.9       |
| **Styling**       | Tailwind CSS 3.4.7   |
| **Animation**     | Framer Motion 11     |
| **UI Components** | Radix UI 1.1+        |
| **Icons**         | lucide-react 0.563   |
| **Utilities**     | clsx, tailwind-merge |

---

## 📊 주요 기능

### 페이지 레이아웃

- **Hero**: 헤더와 인트로 섹션
- **About**: 개발자 소개 및 간단한 이력
- **Skill**: 주요 기술 스택 (섹션)
- **Career**: 경력 정보
- **Projects**: 프로젝트 목록 및 카드
- **Blog**: 블로그 연동 섹션
- **Contact**: 연락처 및 소셜 링크

### 설치

```bash
# 의존성 설치
npm install

# 또는
yarn install
```

### 개발 서버 실행

```bash
npm run dev
```

## 🚀 빌드 및 배포

### 프로덕션 빌드

```bash
npm run build
```

### 프로덕션 서버 실행

```bash
npm run start
```
